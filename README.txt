O servidor também compara pelo nome para tolerar diferenças de idioma/região.
Os preços e a disponibilidade de presentes podem variar por região e ao longo do tempo.

Instalação:
1. Node.js 18+.
2. Abra o terminal nesta pasta.
3. npm install
4. Defina o usuário: PowerShell -> $env:TIKTOK_USERNAME="seuusuario"
5. npm start
6. Abra http://127.0.0.1:8081
7. No OBS, adicione uma fonte Navegador usando a URL do servidor.

O jogo é uma simulação visual e não uma pesquisa eleitoral real.
